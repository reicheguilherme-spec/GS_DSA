## Descrição
Sistema simples desenvolvido em linguagem C para monitoramento de uma missão espacial.

## Funcionalidades
- Inserir dados da missão
- Visualizar status da nave
- Analisar condições do sistema
- Gerar alertas de temperatura, energia e comunicação
- Encerrar o sistema

## Tecnologias Utilizadas
- Linguagem C
- Biblioteca stdio.h
